### 基站排水状态与退出条件补充

基站状态帧 data[23] 按协议 4.2.5 上报当前工作状态。桶体需要根据 0x0C、0x08、0x0A 判断基站处于排水阶段，并在基站切换到后续状态后关闭同步排水。

排水阶段的退出条件如下：

- 正常条件：桶体实时数据上报当前水量为 0L 后，基站继续排水 60s，随后切换到下一工作状态。
- 保护条件：如果基站已经打开排水输出，但一直没有收到 0L 实时水量，最长排水 5min 后自动切换到下一工作状态，避免 data[23] 长时间停留在排水状态。
- 自动清洁 B3 状态序列为 0x0C -> 0x07 -> 0x08 -> 0x09 -> 0x0A -> 0x0B -> 0x03。
- B4 强制排水为 0x0C -> 0x03。B5/B6 喷淋结束后的自动排水均复用 0x0C，结束后回到 0x03。
